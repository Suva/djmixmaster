# Sharing templates

A template is shared as a `.djmtemplate` file, with its pictures, videos and LUTs packed inside.

- **Export** a template from the editor (Export…) or from the ⋯ menu beside the list of templates.
- **Add** one with Import in the ⋯ menu, by dropping the file on the window, or by opening it from Finder or Explorer.

What a template file carries:

- **Pictures** added to it, always.
- **Videos** kept with it. A video of up to 25 MB is copied into the app's own folder when added, so it stays with the template; a larger one is used where it is, and packed in only when the template is exported.
- **LUTs**, kept in it or from your LUT folder. One from the folder is remembered by its name while you work, and packed in when the template is exported.

A template's website and email, from its About page, open in your own browser and mail program when clicked. The app itself contacts nothing.

> A template only describes a picture: its formulas can do nothing but work out numbers and colours. A template file from someone else runs no code of its own, and cannot reach the internet.
